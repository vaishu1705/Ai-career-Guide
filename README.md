# Career Compass AI

Prompt for Lovable

Project Title

AI Smart Career Guidance System

Project Description

Build a modern, responsive, professional frontend for an AI Smart Career Guidance System that helps students discover the most suitable career based on their technical and soft skills.

The frontend should be premium-looking with smooth animations, modern cards, icons, gradients, and responsive design.

Theme should look like a real AI SaaS platform.

Use React + Tailwind CSS + React Router + Framer Motion + Lucide React icons.

No Bootstrap.

Goal

The final UI should look like a professional AI-powered career guidance platform similar to modern SaaS products. It should be elegant, highly interactive, responsive, visually appealing, and suitable for a final-year engineering project demo. It should include polished dashboards, modern cards, smooth animations, attractive typography, and a premium user experience that impresses both faculty and recruiters.
